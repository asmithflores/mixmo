# Data and Analysis

This folder contains the data and analysis materials used in the study.

## Contents

- **data.csv:** Dataset containing children's emotion predictions and associated study variables.
- **explanations.csv:** Dataset containing children's coded explanations of their emotion predictions.
- **EmotionsAndConflictingOutcomes_analysis.html:** Rendered analysis report documenting the statistical analyses and results.
- **Data and Analysis.zip:** Compressed archive containing the data and analysis materials.

Together, these files provide the data and statistical analyses supporting the findings reported in the manuscript.
